# Space Grotesk

`space-grotesk-latin.woff2` is the unmodified Latin subset of Space Grotesk,
with variable weights 300–700, downloaded from Google Fonts:

https://fonts.gstatic.com/s/spacegrotesk/v22/V8mDoQDjQSkFtoMM3T6r8E7mPbF4Cw.woff2
